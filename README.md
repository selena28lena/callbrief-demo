# CallBrief

**CallBrief** — AI-разбор звонков отдела продаж: менеджер загружает запись, а комментарий и задача в CRM заполняются сами.

- **Расшифровка** записи с разметкой «менеджер / клиент»;
- **Комментарий для CRM** — развёрнутая заметка о разговоре, готовая к отправке в карточку сделки;
- **Договорённости, следующий шаг и риски** — у каждого риска совет, что с ним делать;
- **Разбор тренера** — ошибки менеджера с цитатой и таймкодом, готовые фразы, советы на будущие звонки;
- **Интеграция с Битрикс24** — панель прямо в карточке сделки, кнопка «Сохранить в CRM» пишет комментарий и ставит задачу.

У каждого пункта есть **дословная цитата** из разговора, и приложение проверяет, что она действительно есть в тексте.

Как всё устроено — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Как проверяется разметка ролей — `python -m evals.speaker_roles`.

Работает **бесплатно**: используется только бесплатный тариф Google Gemini API.

## Как получить бесплатный ключ Gemini

1. Откройте <https://aistudio.google.com/apikey> и войдите в Google-аккаунт.
2. Нажмите **Create API key** и скопируйте ключ.
3. Вставьте ключ в файл `.env` (см. ниже). Никому не передавайте ключ и не публикуйте его: файл `.env` уже добавлен в `.gitignore`.

> Если Google пишет, что сервис недоступен в вашей стране, для работы с Gemini понадобится VPN.

### Если используется VPN-клиент с прокси (v2rayN, Hiddify, NekoRay и т. п.)

Проще всего включить в VPN-клиенте режим «весь трафик через VPN» (Global) и сервер в стране, где Gemini доступен (например, Нидерланды, Германия, США). Если приложение всё равно пишет «Не удалось подключиться к серверам Google», добавьте в `.env` адрес локального прокси клиента, например:

```
HTTPS_PROXY=http://127.0.0.1:10809
```

Перезапускать сервер не нужно.

## Запуск на Windows

Нужен Python 3.11 или новее. Команды выполняются в папке `callbrief` (PowerShell):

```powershell
python -m venv .venv; .venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # откройте .env и впишите GEMINI_API_KEY=ваш_ключ
uvicorn app.main:app --reload
```

Откройте <http://127.0.0.1:8000>, выберите пример и нажмите **«Проанализировать»**.

### Смена модели

Модель задаётся в `.env`:

```
GEMINI_MODEL=gemini-3.5-flash
```

Если сразу приходит ошибка лимита, возможно, у этой модели нет бесплатной квоты для вашего ключа. Попробуйте `gemini-flash-latest` или `gemini-3.5-flash-lite`. Актуальный список моделей: <https://ai.google.dev/gemini-api/docs/models>. Перезапускать сервер после правки `.env` не нужно.

## Как устроена проверка достоверности

Языковая модель может «додумать» или неточно передать слова. Поэтому каждому пункту она обязана приложить дословную цитату, а сервер проверяет цитату без участия ИИ (файл `app/verify.py`):

1. **Нормализация.** Цитата и исходный текст приводятся к общему виду: нижний регистр, `ё → е`, пунктуация убрана, пробелы схлопнуты. Так «Договорились — в четверг!» и «договорились в четверг» считаются одним и тем же.
2. **Точное совпадение.** Если нормализованная цитата целиком встречается в тексте по границам слов, пункт подтверждён.
3. **Нечёткое совпадение.** Иначе по тексту движется «окно» из стольких же слов (±20 %), и каждое окно сравнивается с цитатой через `difflib.SequenceMatcher`. Если сходство хотя бы в одном окне ≥ **0,85**, пункт подтверждён. Это прощает мелкие расхождения («подготовлю» / «подготовим»), но не пропускает выдуманные фразы.

Каждый пункт получает поле `verified: true/false`, а в ответе есть счётчик «Подтверждено X из Y». Пункт с ❓ не обязательно ложный, но его стоит перепроверить вручную.

Кроме того, в системной инструкции модели прописано: извлекать только явно сказанное; «подумаем», «может быть», «наверное» — не договорённость; сроки указывать только если они названы, в исходной формулировке. Температура генерации низкая (0,15), чтобы ответы были стабильными.

## Интерфейс

- **Главная** (`/`) — один экран без прокрутки: кнопка «Начать бесплатно», карточка загрузки аудио и четыре преимущества. «Возможности» и «Как это работает» открываются во всплывающих окнах. Аудиофайл можно перетащить прямо на первый экран и нажать «Распознать».
- **Анализы** (`/#/app`) — новый анализ: аудиозапись или текст (есть 3 примера).
- **Результат** (`/#/analysis/<id>`) — плеер с волной записи, вкладки «Транскрипция / Договорённости / Следующие шаги / Риски», справа — ключевая информация, резюме, открытые вопросы и следующий шаг. Клик по времени в расшифровке перематывает запись, «Показать в расшифровке» подсвечивает реплику с цитатой. Кнопки: «Скачать отчёт» (.md), «Поделиться» (системное меню «Поделиться» или копирование отчёта), в меню «⋯» — копирование Markdown, скачивание транскрипта .txt, удаление.
- **Архив** (`/#/archive`) — все прошлые анализы с поиском. Хранятся **только в этом браузере**: результаты в localStorage (до 50 штук), аудио до 100 МБ — в IndexedDB. На сервер ничего не сохраняется.
- **Настройки** (`/#/settings`) — статус подключения к Gemini, модель, очистка архива.

## Аудио

На вкладке **«Аудио»** можно загрузить файл mp3, wav, m4a или ogg. Gemini дословно расшифрует разговор и разметит реплики «Менеджер:» / «Клиент:». Текст появится в поле ввода: проверьте его и нажмите «Проанализировать». Файлы до 20 МБ отправляются прямо в запросе, более крупные (до 200 МБ) загружаются через Files API Gemini и удаляются после расшифровки.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/` | интерфейс |
| GET | `/api/health` | есть ли ключ и какая модель выбрана |
| GET | `/api/examples/{1..3}` | текст примера |
| POST | `/api/analyze` | `{"text": "..."}` → отчёт с проверкой цитат |
| POST | `/api/transcribe` | multipart `file` → `{"text": "..."}` |

## Тесты

```powershell
pytest -q
```

Тесты проверяют логику сверки цитат (точная цитата, другая пунктуация и регистр, ё/е, выдуманная цитата, нечёткое совпадение) и не обращаются к Gemini API.

## Ограничения

- **Лимиты бесплатного тарифа.** У бесплатного тарифа Gemini есть ограничения на число запросов в минуту и в день (актуальные значения видны в Google AI Studio). При ошибке 429 приложение делает одну повторную попытку, затем просит подождать минуту.
- **Качество распознавания аудио** зависит от записи: шум, перебивания, плохой микрофон. Модель может перепутать, кто говорит. Всегда проверяйте расшифровку перед анализом.
- **ИИ может ошибаться.** Проверка цитат ловит выдуманные фразы, но не гарантирует верной трактовки. Отчёт — помощник, а не замена прослушиванию разговора.
- **Только обезличенные данные.** На бесплатном тарифе Google может использовать запросы для улучшения своих моделей. Не загружайте имена, телефоны, адреса и другие персональные данные клиентов.
- Максимальная длина текста — 200 000 символов.
